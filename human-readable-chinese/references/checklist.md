# 流程、自检与翻车清单

改写前读 `diagnosis.md`，改写时查 `rewrite-rules.md`，交付前用这一页。

---

## 一、五步流程

不要凭语感一次改完。后两步是质量保证，别跳。

**Step 1 抽主干表** — 逐句抽「主语 | 谓语 | 宾语 | 主谓距离」。抽不出主谓宾的句子，就是有病的句子。

**Step 2 按病开刀** — 给每句标病灶号（1~9），按 R1→R11 顺序改。优先修 1、3、4。

**Step 3 补连接** — 拆句后检查：句与句之间的因果、转折、条件，还有显式词承载吗？没有就补。

**Step 4 保真核对** — 把改前的每个数字、条件、专有名词列出来，在改后文本里逐个找到。**找不到的就是丢了。**

**Step 5 朗读测试** — 念出声。卡住的地方就是要改的地方，尤其能抓出「主语句内漂移」。

## 二、自检清单（交付前逐条过）

**结构**

- [ ] 每句都能抽出主语、谓语？
- [ ] 主语中心词到谓语动词 ≤ 8 字，中间没夹逗号？
- [ ] 主干没被「针对……的」「基于……的」这类空壳包住？
- [ ] 一个句子里「的」不超过 2 个？
- [ ] 超过 40 字的句子已拆，且拆完补了连接词？

**用语**

- [ ] 主语是能做那个动作的东西（人/团队/系统/服务），不是「体系/链路/能力/维度」？
- [ ] 没有「进行/实现/开展/推动/构建 + 抽象名词」？
- [ ] 术语首次出现就地解释了？
- [ ] 抽象形容（显著/大幅/有效）后面跟了数字或事实？

**可信度**

- [ ] 数值、条件、边界、例外一个没丢？
- [ ] 每个精确数字都能指回出处？转述的结论没被改强？（R10）
- [ ] 这段里的比喻不超过一个，且没有用它盖住没说清的地方？（R11）

**整体**

- [ ] 念一遍不卡？扫一眼能回答「谁遇到什么、要我干什么」？

## 三、想量化时的抽查指标

随机取 5 句，数三个数：

| 指标 | 目标 |
|---|---|
| 平均句长 | 20~30 字 |
| 主谓距离中位数 | ≤ 8 字 |
| 无生主语句占比 | 0 |

**三个数别混**：主谓距离、头名词位置、整句长度是三个量，见 `diagnosis.md` 第四节。

## 四、翻车清单

| 错误做法 | 为什么错 |
|---|---|
| 为了短而机械断句 | 连接词一删，逻辑关系要读者自己补，认知负荷反升。**注意**：这条结论说的是认知负荷，不要说成「答题准确率下降」，那是另一组实验的指标 |
| 编一个精确但没出处的数字 | 「200 毫秒」「提升 47%」听起来专业，读者会信。精度不能靠脑补（R10） |
| 每段塞两三个比喻 | 读者觉得懂了，其实没懂。比喻是解释工具，不是内容本身（R11） |
| 把「我们」堆成口号 | 「我们将持续优化体验」没有主语价值，它不是人，是空气 |
| 删掉限定条件和例外 | 可读性以保真为前提。这是最严重的失败 |
| 改成 PPT 体（一行一句、全是名词短语） | 名词短语没有主谓，同样难读，只是换了一种难读 |
| 把术语全换成大白话 | 该留的要留，只是要就地解释（R8） |
| 只改一句，不改结构 | 一段话的信息顺序本身是乱的，句子改得再顺也没用 |

---

## 五、提示词里最容易写错的一句

**别写「句子越短越好」。** 它会诱导模型删连接词、机械断句，逻辑关系丢给读者补，比原来更累。

要写的是：**主语到动词不超过 8 个字；数字、条件、例外一个不许删。**

更多反面提示词见 `prompt-snippet.md`。
